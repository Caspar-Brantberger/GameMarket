# GameMarket

GameMarket is a hobby project for a simple game marketplace inspired by platforms like Blocket.  
The goal is to build a small full-stack application where users can browse, filter, view, and eventually create listings for video games.

This project is mainly built as a learning project to practice modern full-stack development with Next.js, Node.js, TypeScript, and PostgreSQL.

## Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- Express
- TypeScript

### Database
- PostgreSQL
- Prisma planned for database access
